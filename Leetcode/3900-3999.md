# Leetcode Problem 3900-3999

# [3903. Smallest Stable Index I](./3903_smallestStableIndexI.md) 🌟

### Brute Force

-   For each index, scan left for the prefix max and right for the suffix min.

### Prefix Max Array + Suffix Min Array

-   Precompute both preMax[i] and suffMin[i] in one pass each, then scan for the first index where preMax[i] - suffMin[i] <= k.

### Running Max + Suffix Min Array

-   Same idea, but the prefix max is folded into a single running variable instead of its own array.
